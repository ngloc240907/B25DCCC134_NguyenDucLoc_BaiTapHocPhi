HƯỚNG DẪN CHẠY CHƯƠNG TRÌNH
==================================================
Yêu cầu: Máy đã cài đặt JDK (Java Development Kit 8 trở lên).

Cách 1: Chạy bằng Terminal / Command Prompt
1. Giải nén file BaiTap_HocPhi_Java.zip.
2. Mở Terminal / CMD tại thư mục vừa giải nén.
3. Di chuyển vào thư mục câu cần chạy (ví dụ Câu 1):
   cd Cau1
4. Biên dịch file Java:
   javac Main.java
5. Chạy chương trình:
   java Main
6. Nhập dữ liệu đầu vào từ bàn phím theo đúng định dạng đề bài và nhấn Enter để xem kết quả.
(Thực hiện tương tự cho các thư mục Cau2, Cau3, Cau4).

Cách 2: Chạy trực tiếp trên VS Code / IDE
1. Mở file Main.java trong thư mục câu tương ứng.
2. Nhấn nút Run để biên dịch và chạy.
3. Nhập dữ liệu đầu vào tại cửa sổ Terminal để kiểm tra kết quả.
